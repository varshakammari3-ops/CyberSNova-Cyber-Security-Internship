# CyberSNova Cyber Security Internship

## About the Internship

This repository contains the practical work completed as part of the CyberSNova Cyber Security Internship.

The internship work covered two completed levels:

- Beginner Level
- Advanced Level – OverTheWire Bandit

## Beginner Level

The Beginner Level consisted of four practical projects:

### Project 1 – Network Reconnaissance & Service Enumeration
Tools used:
- Nmap
- WhatWeb
- Netcat

### Project 2 – Hidden Directory & File Enumeration
Tools used:
- Gobuster
- Dirsearch
- Dirb

### Project 3 – Login Traffic Analysis
Tools used:
- Wireshark
- Burp Suite Community Edition

### Project 4 – Basic Web Vulnerability Assessment
Tools used:
- Burp Suite Community Edition
- Nikto

## Advanced Level

### OverTheWire Bandit – Levels 0–20

The Advanced Level was completed through the OverTheWire Bandit challenge from Level 0 to Level 20.

The work involved practical use of:

- Linux command-line tools
- File and directory analysis
- Text processing
- Encoding and decoding
- SSH
- OpenSSL
- Network connections
- Privilege execution
- Problem-solving and troubleshooting
